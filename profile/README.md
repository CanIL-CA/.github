# Canada Institute of Linguistics

The [Canada Institute of Linguistics (CanIL)](https://www.canil.ca) equips linguists to serve marginalized communities through language development, revitalization, and Scripture translation.

This is where CanIL's research and innovation work lives in the open.

## Projects

- **[TaBiThA](https://tabitha.bible)**: a translation platform built around a semantic encoding of the biblical text, with tools for sources, ontology, target-language lexicons, and AI-assisted translation guidance.
